# Embedded profile fonts

The profile SVG assets use self-contained WOFF2 subsets so the intended typography renders without external network requests.

| Family | Role | Source | License |
| --- | --- | --- | --- |
| Space Grotesk | Display titles | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) | SIL Open Font License 1.1 |
| IBM Plex Mono | Technical labels | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) | SIL Open Font License 1.1 |
| Inter | Body and interface text | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter) | SIL Open Font License 1.1 |

The corresponding license texts are included in this directory. The generated SVG files embed only Latin/Latin-extended WOFF2 subsets required by the profile content.
